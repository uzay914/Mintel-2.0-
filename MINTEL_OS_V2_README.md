# MintelOS Control Center — Private Beta v2.0

This is a fictional CPU utility for a Windows 11 VMware virtual machine.

## Build

1. Keep `MintelOSControl.cs`, `MintelOS.ico`, and `Build-MintelOS.cmd` together.
2. Double-click `Build-MintelOS.cmd` on Windows 11.
3. If compilation succeeds, run `MintelOSControl.exe`.

The builder uses the .NET Framework 4.x C# compiler included with many Windows installations. If your VM doesn't have it, install the Windows .NET Framework development tools and run the builder again.

## Features

- Dashboard: fictional processor, MintBoost, MintCache and power profiles.
- CPU Profiles: fictional processors and MintBench.
- RGB Silicon: on-screen color previews only.
- Diagnostics: read-only Windows VM information.
- MintLab: fictional thermal and stability simulations.
- Activity: session events and export.
- v2 Features / Monitor: Windows CPU utilization (if performance counters work), system RAM usage and application memory.
- v2 Features / System Tray: minimize, restore and exit via a tray icon.
- v2 Features / Updates: offline fictional update catalog, no downloads.
- v2 Features / Gaming: simulated optimizations only.
- v2 Features / Themes: changes only Control Center colors; Save Settings persists the selection.
- v2 Features / Health: read-only disk space and file checks.
- Dashboard / Startup: optional, user-confirmed launch after Windows sign-in. Click again to disable. The EXE must remain at the same path.

This software does not change drivers, CPU voltages, real fan speeds, Windows boot settings or the existing Mintel boot logo. Mintel is a fictional CPU brand used for education and entertainment, not affiliated with Intel, AMD, or the existing Mintel market-intelligence company.

## Troubleshooting

If the builder shows errors, take a screenshot of the command window. The program has not been compiled or runtime-tested by the authoring environment.
